# Chromesthesia

A music visualizer that paints a song the way someone with sound-to-color synesthesia might see it. Each of the 12 notes has its own color; loud, bright sounds glow neon and quiet, low ones stay dull.

**Styles (keys 1–9):** Watercolor, Oil impasto, Shapes, Crystal, Ink in water, Aurora, Ink brush, Pointillism, Crystal cave.

**Music sources**
- Open or drop a music file (MP3, WAV, M4A, FLAC, OGG).
- Listen to a browser tab: play a song on YouTube or Spotify in another Chrome or Edge tab, choose *Listen to a browser tab*, pick that tab and tick *Also share tab audio*.
- Built-in demo loop.

It's a single static `index.html` with no build step, so any static host works.
