# The Sound of Color · Ink in water

Start with the working comparison in `ink.html`. The public preview is https://nguyenemily408.github.io/chromesthesia/ink.html and the GitHub branch is `codex/ink-comparison`.

Use `ink-fade.jpg` and `ink-painting.jpg` as visual references. Aim for slow, billowing folds, rich color, and clouds spreading across a white canvas. The screenshots show the desired composition and texture. The live ink should continue to react to the music. The original reference emphasizes the soft curling folds where cyan, blue, and violet meet. Keep the full note palette for the actual music.

- **Fade with music** lets older pigment dissolve while new notes add clouds.
- **Build a painting** keeps the pigment, holds the final frame when playback ends, and offers a PNG.
- Both modes use the same 18-second demo or a song file the listener chooses. Switching modes brings the track back to the beginning.
- The current version estimates notes from the audio and uses their strength to size the clouds. It does not identify individual instruments.

Compare both modes using the same track. Show a browser preview and a screenshot of each mode before publishing visual changes. For a first real-song comparison, use the opening of Beethoven's Fifth Symphony, then try Bach's Prelude in C major, BWV 846.
