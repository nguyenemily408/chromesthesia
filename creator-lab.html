About Creator MCP

Creator MCP is a model context protocol server that lets an AI agent build Lottie animations programmatically via the LottieFiles Creator API. It exposes tools like creator_exec for running JavaScript against a persistent composition document, creator_preview for live review, and creator_download_file for fetching the exported JSON.

This animation was composed end-to-end by a Claude session: the composition was created, keyframes were set with ease-in-out tangents, an 8-frame filmstrip was rendered for verification, and the Lottie JSON was exported and saved — all without touching any existing renderer code in the gallery.
